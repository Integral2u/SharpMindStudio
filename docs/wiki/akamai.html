Akamai Cloud (Linode)

Akamai Cloud Computing is the Linode platform. Studio can create a Linode through the Linode API v4, attach a cloud firewall, wait for its public address and run the same SSH setup used by Vultr. Existing Linode SSH keys only: Studio never uploads a private key.

GPU types where the region offers them ports 5117 + 8080 hourly billing
No Akamai Cloud account? Open Akamai Cloud
Billing does not stop when the Linode is powered off. Destroy the instance when the run is done. Studio shows a Destroy button on the host card and on the Compute page.

Before you start

  • An Akamai Cloud account with billing enabled.
  • A Linode personal access token with Account: Read Only, Images: Read Only, Linodes: Read/Write and Firewalls: Read/Write.
  • An SSH key already saved in the Linode profile.
  • The SharpMind server image in a registry the instance can pull, for example integral2u/sharpmind-server:gpu.
  • A region that advertises GPU Linodes when you want GPU training. CPU-only types work in every region.

Create the API token

  1. Open cloud.linode.com/profile/tokens.
  2. Create a personal access token with exactly these categories:
    • Account: Read Only - account balance and the profile SSH keys.
    • Images: Read Only - the Ubuntu image list.
    • Linodes: Read/Write - create, read and delete the instance.
    • Firewalls: Read/Write - create, attach and delete the cloud firewall.
    Leave the other categories at None.
  3. Paste the token into the Akamai panel on the host card and press Load account. The token is stored encrypted and is checked before it is saved.

Add an SSH key

Add the public half of the key to the Linode profile, not to an individual instance. In Studio, edit the host and select the matching local private key under SSH key file. The Akamai panel lists the keys already in the profile; Deploy stays disabled until one is selected and the private key is set.

Add a key at cloud.linode.com/profile/sshkeys. The private key never leaves this PC.

Add the host in Studio

  1. Settings → Providers → Compute → Add host.
  2. Choose Akamai Cloud (Linode).
  3. Name the host, generate the SharpMind bearer token, and set the server image. The image needs a registry prefix, for example integral2u/sharpmind-server:gpu; a local tag such as sharpmind-server:gpu cannot be pulled.
  4. Set the SSH login: user root, port 22, and the local private key that matches the Linode profile key.
  5. Tick GPU host when the selected type has a GPU. Save the host.
  6. On the host card, load the account, then choose the region, type, image and SSH key.
  7. Press Deploy instance in the Akamai panel. The generic SSH buttons stay hidden until the instance has a public address; do not use them before deploying.

Deploy from the API

Studio creates a cloud firewall for TCP 22, 8080 and 5117, creates the Linode with the selected profile key, attaches the firewall, waits for the public IPv4 address, then waits for SSH and runs the installer. The instance is tracked before the wait, so a failed setup still leaves a destroyable record.

GPU types are region-specific. The panel hides GPU types when the selected region does not advertise GPU Linodes. Pick a GPU region first when the purpose is training.

Verify and train

  • Refresh reads the Linode status and updates the Base URL and Studio URL when the public address is available.
  • The host card's Test checks /health and reads the model list.
  • In Training → Run on, choose the Akamai host. Training from scratch needs no model on the host.
  • For Chat, upload a model to the host and select it in the model chooser.

Cost and cleanup

Linode bills hourly. A powered-off Linode still bills until it is deleted. Press Destroy instance on the Akamai panel to delete the Linode and its firewall. Export any trained model before destroying the host.

The panel's Destroy when idle setting starts a 10-minute Keep countdown after the host has been idle for the selected window. The sidebar warning offers Keep or Destroy now, and destroying removes the Linode and its firewall. The Compute page lists Akamai instances beside Vultr instances, with the same hourly and spent totals, and the left menu shows them under Compute.

Common problems

MessageMeaning
401 Invalid TokenThe token is wrong, expired, or missing a required scope. Create a new token with Account/Profile read and Linodes/Firewalls read/write.
No SSH keyAdd a public key to the Linode profile, then press Load account and select it.
GPU types are missingThe selected region does not advertise GPU Linodes. Choose a GPU region or a CPU type.
SSH did not openThe Linode is running but port 22 is blocked. Check the cloud firewall and the host's SSH key.
The instance did not boot in 20 minutesRefresh to check the Linode status, or Destroy it to stop billing and try another region/type.
