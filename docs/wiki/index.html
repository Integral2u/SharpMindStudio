What works today

The support matrix.

This PC covers the Studio process and an optional Local Docker host on the same machine. A local NVIDIA GPU is used only when the GPU image and Docker runtime are present. A Compute host always brings its own device.

CapabilityThis PC / Local DockerCompute hostNotes
Chat with a packaged modelYesYesOne active model per process on a host.
OpenAI-style API—YesBearer token; /v1/chat/completions, models, files, training jobs.
Pretrain from scratchYes (CPU)Yes (CPU)The GPU engine refuses whole-weight training by design.
LoRA fine-tuneYes (GPU or CPU)Yes (GPU or CPU)GPU needs RMSNorm + RoPE/NoPE + gated FFN; otherwise the CPU retry runs.
SFT (assistant-only loss)Yes (GPU or CPU)Yes (GPU or CPU)Chat JSONL; the base supplies the tokenizer and template.
GPU inferenceWith a supported local GPUYes (GPU or CPU)Also covers LayerNorm and dense-GELU models.
